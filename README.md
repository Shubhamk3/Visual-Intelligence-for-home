# Visual-Intelligence-for-home
An open source Hardware project which will assist you daily using ML and AI

It's been ages since the launch of ChatGPT, Gemini, Grok etc. and most of it are used by the Programmers. So I have decided to make a project which includes some hardwares and can be used in our day to day lives.

Objective:

Needful:
**Microprocessor - FS32V234CON2VUB:**
Quad Cortex-A53 cores running up to 1GHz,
Dual APEX-2 vision accelerator cores
MIPI CSI2 and parallel image sensor interfaces
Embedded image sensor processing (ISP) for HDR, color conversion, tone mapping, etc
3D GPU (GC3000)

**Camera - IMX219PQH5-C** 
Supports multiple frame rate like 30, 60 and 180 FPS
8MP with maximum resolutions of 3280 x 2464
Provides High-quality image with low noise and good light sensitivity

**IMU Sensor for motion/gesture - BNO055**
3-axis Accelerometer, 3-axis Gyroscope, 3-axis Magnetometer (9-DoF)
Euler Angles, Quaternions, Rotation Vectors
Supports auto-calibration with persistent offset memory
Internal 32-bit ARM Cortex-M0 for fusion processing
Linear acceleration, Gravity vector, Angular velocity, Magnetic field

**Edge AI accelerator(Optional) - Google Coral, Hailo-8**


**Microphone array - INMP441**
Supports stereo/channel configuration using L/R select pin
Digital I²S Interface with High-Precision 24-Bit Data
High SNR of 61 dBA
High Sensitivity of -26 dBFS
Low Current Consumption of 1.4 mA

**Ethernet DP83826** 
Supports 10 Mbps, 100 Mbps (full-duplex and half-duplex support)
Auto negotiation(Speed and duplex)
Auto MDIX(automatically Switches RX/TX pairs)
Basic cable length and short/open detection

Wifi
ROM
RTC
Temp and humidity sensor
touch display
